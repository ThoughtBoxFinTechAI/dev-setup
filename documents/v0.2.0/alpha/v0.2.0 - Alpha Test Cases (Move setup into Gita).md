## How the tests were run

- **Gita:** `flutter test test/unit` on Windows 11 with Dart 3.12.2: 331 pass and 17 skip (#23's own `gita gh` tests skip on Windows by design; they run on Gita's macOS/Linux CI). Before the rebuild on #23/#21: 341 pass. `dart analyze`: no issues. The CLI built with `dart build cli` passes `scripts/smoke_cli.sh`.
- **Isolation:** every test used a throwaway home (`HOME`, `USERPROFILE`, `LOCALAPPDATA`, `GIT_CONFIG_GLOBAL`, `GIT_CONFIG_NOSYSTEM=1`) and a fake password store, or none. SHA-256 of the developer's real `~/.gitconfig` and `~/.gita/*.json` were the same before and after every run (see the incident in the Change Request history).
- **dev-setup scripts:** Windows PowerShell 5.1 (parser also on 7.4.6) with `TB_GITA_ZIP` built from the local Gita, and WSL Ubuntu for `install.sh`. shellcheck 0.10.0.
- **Bump bot:** WSL, with the real Gita 1.0.2 release files served by a fake `gh`.
- No real GitHub sign-in, no real Credential Manager change and no Mac in any run.
