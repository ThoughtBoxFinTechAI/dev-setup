## How the tests were run

- **Windows 11, Windows PowerShell 5.1:** a test harness loaded only the Figma functions
  from `install.ps1` (parsed from the script, unchanged) and pointed the install folder at
  a temp folder instead of `~/.thoughtbox`. The full setup (Gita, sign-ins) was not re-run.
  Real downloads from npm and GitHub, real checksums. The Claude Code entry it added was
  removed after the test.
- **bash logic:** `install.sh`'s functions sourced in Git Bash on Windows with
  `os=macos`. `ditto` (macOS only) was replaced by `unzip`, and, because GitHub returned
  504 to Git Bash's `curl` at the time, `curl` was replaced by a copy of the release zip
  downloaded earlier and checked against GitHub's published SHA-256. Homebrew, the Figma
  app check and `claude mcp add` on macOS are left to CI.
- ShellCheck could not run locally (its binary download got a 504); the CI `lint` job runs it.
