## How the tests were run

- **Windows 11:** `install.ps1` ran in Windows PowerShell 5.1 with `-NonInteractive`, in a
  throwaway home: `HOME`, `USERPROFILE`, `LOCALAPPDATA` and `GIT_CONFIG_GLOBAL` pointed to a
  temp folder, `GIT_CONFIG_NOSYSTEM=1`. Fake `gh` and `cmdkey` commands stood in for the real
  ones, so no real account was touched. The user PATH was saved before and restored after.
  Gita was the real pinned v1.0.2 download, checked against its SHA-256.
- **Linux:** `install.sh` ran in WSL Ubuntu in a throwaway home, without a terminal
  (`setsid -w </dev/null`).
- Old settings were planted with fake values only (`FAKEVALUE`, `SECRETVALUE`): a saved
  github.com login, a token `insteadOf` rule, a github.com sign-in header, a gh login,
  a Credential Manager entry, plus a gitlab.com rule and an example.com login that must stay.
- `TB_SKIP_SIGNIN=1` in all runs: the browser sign-in was not tested here.
